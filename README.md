# ChatGPT Image Skill — Documentary Fundraising/Dawah Campaigns

A reusable instructions file for generating or editing campaign images in ChatGPT (gpt-image), in a warm, documentary, testimonial style — no corporate stock-photo look, no altered faces, no invented elements.

**Important:** this produces static images only. It does not generate video (no camera push-in/pan/tilt). If you need video, use an image-to-video tool (Higgsfield, Runway, Kling, etc.) starting from the image this skill produces.

## How to use it

1. Open [`SKILL.md`](./SKILL.md).
2. Paste its full content as the instructions of a ChatGPT Custom GPT, or as the first message of a conversation, or upload it as a knowledge file in a ChatGPT Project.
3. For each piece: attach your real source photo, fill in the prompt template with the scene description, and ask ChatGPT to generate/edit the image accordingly.

## What's in this repo

- `SKILL.md` — the full skill: style rules, do's/don'ts, reusable prompt template, and a 15-prompt example series for a dawah/fundraising social campaign.

## Privacy

This repo is generic by design: it contains no real photos, no real donation links, and no private campaign data. Those stay local to your own ChatGPT conversation.
